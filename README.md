# Superstore Sales Analysis Using SQL

## Objective

Analyze sales data using SQL with filtering, aggregation, and business queries.

## Dataset

Superstore Dataset (Kaggle)

## Technologies Used

* Python
* Pandas
* SQLite
* Jupyter Notebook
* SQL

## Tasks Performed

### 1. Data Loading

* Imported Superstore CSV dataset
* Loaded data into SQLite database

### 2. Data Exploration

* Viewed schema
* Examined sample records
* Checked column data types

### 3. Filtering

Applied SQL WHERE conditions on:

* Region
* Category
* Sales
* Order Date

### 4. Aggregations

Used GROUP BY to calculate:

* Total Sales
* Total Quantity
* Average Sales

### 5. Sorting and Ranking

* Top Products
* Top Categories
* Top Customers

### 6. Business Analysis

* Monthly Sales Trends
* Customer Analysis
* Duplicate Record Detection

### 7. Data Validation

* Row Count Verification
* Missing Value Checks
* Data Quality Validation

## Key Insights

* Technology products contributed significantly to revenue.
* Sales performance varied across regions.
* Top customers generated a large share of total sales.
* Monthly sales trends revealed business seasonality.
* Dataset quality was verified using validation queries.
